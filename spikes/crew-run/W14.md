## Penyimpangan dan temuan (untuk lane lain dan konduktor)

1. `{@catalog}` memicu warning analyzer `doc_directive_unknown` (gate "0 issue" gagal). Di `surface.dart` dan `pressable.dart` saya
   pakai `// ignore_for_file: doc_directive_unknown` dengan komentar alasan (lint `document_ignores` menuntutnya). Setiap file widget
   lane B sampai G akan butuh baris yang sama, atau satu entri `analyzer: errors: doc_directive_unknown: ignore` di
   `analysis_options.yaml` (file milik lane I; saya tidak menyentuhnya). Rekomendasi: konduktor memutuskan satu cara sebelum lane B sampai G mulai.
2. `SurfaceHost` diberi jarak 8 px dari tepi jendela (`hostInset`), dan widget mendapat constraint loose `size` dikurangi 16.
   Tanpa itu `androidTapTargetGuideline` melewati setiap node yang menyentuh tepi view, sehingga cek ukuran target tak pernah berjalan.
   Ini mengubah teks desain "Align(topLeft) dengan loose(size)" sedikit. Golden `golden_setup_*` dibuat ulang karena host berubah.
3. Gambar golden berukuran 1x (400x160 untuk galeri 400x160): view diset DPR 2, tetapi `matchesGoldenFile(finder)` menangkap pada rasio 1.0.
   Hairline 0.5 px (Req 11.2) belum terlihat di PNG. Tidak diubah; perlu keputusan sebelum lane widget membuat golden (lihat `S5-A2.md`).
4. `expectLater` tidak bisa membungkus `runStressCase` (keduanya API tes terjaga, "Guarded function conflict"). Tes diri harness memakai
   `try/catch TestFailure`, bukan `throwsA`.
5. A3 menambah pemeriksaan kategori blok katalog harus sama dengan kategori di inventaris (di luar teks task, lebih ketat). Flag
   `coreInventoryStrict` ada di `test/helpers/core_widget_inventory.dart` (Z2 mengubahnya ke true).
6. A1: `.gitignore` root sudah punya `**/test/**/failures/`; aturan `test/**/failures/` ditambahkan juga ke `skeleton/.gitignore` sesuai task.
7. Profil `full` memakai DPR 2.0 untuk touch dan 1.0 untuk pointer (spesifikasi tidak menyebut DPR untuk profil ini).
8. `stressTest` menjalankan `setUpAll(loadInterFont)` per pemanggilan; `loadInterFont` idempoten per file. Di dalam `testWidgets`, `loadInterFont()` menggantung
   (FakeAsync), jadi harus lewat `setUpAll`.
