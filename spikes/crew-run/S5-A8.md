# S5-A8: compile check of the core widget API

Scratch file: `skeleton/lib/core/_api_stubs.dart` (608 lines). It declares every public signature of the
design section "Components and interfaces" with `throw UnimplementedError()` bodies: the 25 widgets, the helper enums and data
types (`AppButtonSize`, `ActionGroupGap`, `AppSegment`, `AdaptiveDestination`, `ToastRequest`), `ToastController` with
`@lazySingleton`, `feedbackCell`, `showAppDialog`, `showConfirm`, `showAppSheet`, and a `probe(BuildContext)` function that
touches the tokens the design relies on: `context.hue(HueRole.danger)`, `context.sizes.{control,compact,pill,badge,row,toggleTrack}`,
`surface.{button,primary,toggle,badge(hue),line}`, `palette.{scrim,alphaA3,alphaA4}`, every `AppOverlay` constant, `AppLayout`,
`AppSpace.s16/s48/s64`, `AppRadius.sheet/full/containerAll`, `AppMotion.d0` to `d6000`, `AppSprings.toggle`,
`cssBlurToFlutter`, `Debouncer`, the six new ARB keys, `Pressable(pressedScale, semanticLabel)`, `PageRouteBuilder(opaque,
barrierDismissible, barrierLabel)`, `Tooltip(waitDuration: AppMotion.d0)`, and an exhaustive `switch` over the seven `Failure`
subtypes. `ThemeModeSwitch` was written out in full against `AppSettingsCubit.setThemeMode` and `AppThemeMode`.
`build_runner` was not run, so the scratch `@lazySingleton` never reached `injection.config.dart`.

## Design errors found and fixed

1. Icon names. The design wrote `LucideIcons.monitor300`, `.sun300`, `.moon300` (and `Icon(LucideIcons.xxx300)` in the
   rules list). In `lucide_icons_flutter` 4.0.3 the weight 300 icons are the class `LucideIcons300` with plain names
   (`LucideIcons300.monitor`, `.sun`, `.moon`), imported from `package:lucide_icons_flutter/lucide_icons_300.dart`. The design
   now says so in two places (rule 5 of "Rules every widget follows" and the `ThemeModeSwitch` text). `requirements.md` already
   said `LucideIcons300`, so it is unchanged.

No token was missing, so A5's list did not change. Every other signature compiled as written, including the default
`AppOverlay.dialogDefault` for `AppDialog.width`, `SearchField.defaultDebounce = AppMotion.d400`, `AppSpace.s16` for the grid gap,
and the exhaustive `Failure` switch.
