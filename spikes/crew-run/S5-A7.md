# S5-A7: can a `kiri_check` `forAll` block drive a render?

Spike time: about 15 minutes. Result: **no. The fallback of the design was taken.**

## Preferred path, tried

A `property` with `forAll(string(maxLength: 20), (s) async { ... })` whose block called
`TestWidgetsFlutterBinding.ensureInitialized()`, `binding.attachRootWidget(binding.wrapWithDefaultView(Text(s)))`,
`binding.scheduleFrame()`, `await binding.pump()`.

It fails at once:

```
Failed assertion: line 2250 pos 14: 'inTest': is not true.
  AutomatedTestWidgetsFlutterBinding.pump (package:flutter_test/src/binding.dart:2250)
```

`forAll` blocks run inside a plain `test` registered by `kiri_check`, not inside `testWidgets`. There is no `WidgetTester`
(its constructor is private), and the binding's `pump` only works inside a `testWidgets` run. Driving `drawFrame` by hand
would need a copy of the tester's setup (view size, error capture, semantics) and was not tried.

## Fallback taken (design, step 2)

`stressProperty` in `skeleton/test/helpers/stress_property.dart`:

1. `property(...)` with `forAll(combine2(string(maxLength: 120), integer(...)), samples.add, seed: 20260126, maxExamples: 20)`
   draws 20 samples with `kiri_check` arbitraries and the fixed seed.
2. One `testWidgets` registered right after renders every sample in the three `normal` cases of the quick profile
   (320×640 touch light, 1600×900 pointer light, 375×812 dark) through `runStressCase`. Tests of a file run in registration
   order, so the property runs first. The render test asserts that samples exist.

`kiri_check` is still used to generate the data, so Req 9.8 is met in the way its second sentence allows: the fixed seed is
kept and the deviation is that the render is not inside the `forAll` block. The README deviation list gets one line in Z1.

## Findings

- The generator draws lone surrogates, which `Text` rejects (`string is not well-formed UTF-16`). The sample is passed
  through `utf8.decode(utf8.encode(raw))`, which replaces them with U+FFFD.
- Two properties with the same seed draw the same 20 strings, and seed 7 draws other strings (test in
  `stress_property_test.dart`).
- A failure message names the case label and the sample index, text, and number.

## Not proven

Shrinking does not apply: a failing sample is reported as drawn, not minimised.
