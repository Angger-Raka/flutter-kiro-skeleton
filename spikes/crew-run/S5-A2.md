# S5-A2: golden stability (Req 11.7)

Host: this Mac (macOS). Test: `skeleton/test/helpers/golden_test.dart`, tag `golden`.

Procedure: `flutter test --tags golden --update-goldens test/helpers/golden_test.dart`, hash the PNGs,
run it a second time, hash again, then `flutter test --tags golden` (compare mode).

Result: SHA-256 equal across the two update runs, and the compare run passed.

```
ae75c37741f8bc1dd976d081ff3eb682b135636cfcc4a9196ca0d90fd971d9bc  golden_setup_dark.png
662a048d4c8200c9bd283a11c3f59cb691c13498ab633d11a6dc789a66a7e215  golden_setup_light.png
```

No tolerance comparator is used.

Finding: the images are 400x160 for a 400x160 logical gallery. The view is set to device pixel ratio 2,
but `matchesGoldenFile` on a finder captures at pixel ratio 1.0, so the PNG is 1x. The 0.5 px hairlines of
Req 11.2 are therefore not visible at 2x in these images. Not changed in A2; a widget lane or the user
should decide whether to capture at 2x (for example a custom comparator or `captureImage` with a ratio).
