# C6 — Spaceflight News API (S14)
- Date: 2026-11-17
- Results: S14: API v4.37.1 lists 42 news sites (`/v4/info/`). Filter format is comma-separated in one `news_site` param (docs: "list of comma-separated values, case insensitive"). Counts of `/v4/articles/`: NASA=7049, ESA=2202, `news_site=NASA,ESA`=9251 (7049+2202, a union), `NASA%2CESA`=9251 (encoded comma works too), `news_site=NASA&news_site=ESA`=2202 and the reverse order gives the NASA-only count (a repeated key is NOT a multi-value filter, only one value is used, apparently the last). A name with a dot or space works: `Space.com`=731, `Space.com,NASA`=7780, `The%20Verge,ESA`=2205. Also exists: `news_site_exclude`. `offset` is capped at 10,000 (page deeper with `published_at_lt`). Response headers: no rate-limit headers (no X-RateLimit-*, no Retry-After); only `cache-control: max-age=600`, served via Cloudflare, so the client should cache about 10 minutes. No documented limit, so be gentle. Python's default `Python-urllib` User-Agent got HTTP 403 once; curl and any custom User-Agent get 200, so the Dart client should send its own User-Agent. Attribution and image rights: the API docs, the site (spaceflightnewsapi.net) and the GitHub README (TheSpaceDevs/spaceflightnewsapi) state no licence, terms page or attribution rule (/terms and /about return 404, GitHub reports no licence). The site only asks for donations (TSD Patron). Each article has `url` (original) and `image_url`, which points at the publisher's own server (for example assets.science.nasa.gov), so the images are third-party content owned by each news site. Decision: plan kept for using the API (use `news_site=A,B`); the images are not cleared for the video.
- Recommendation for the video and screenshots: do not show real article images or headlines from the live feed. Use placeholder or own-made images and fake or generic article titles, or show only text with the source name and a link. If a real image is wanted, use only NASA ones (NASA media is generally not copyrighted, but check NASA's media usage guidelines first) and credit the source. In the app UI, show the news site name and link to the original `url` for attribution, and credit "Spaceflight News API (The Space Devs)" in the README/About. This is a reading of public pages, not legal advice.
