# W13: logo/splash kosong

## Penyebab
Aset placeholder dari W6 (7.1) berupa kotak polos, bukan logo. Dibaca langsung dari PNG (dekode zlib, hitung warna unik): `icon.png`, `og.png` dan semua ikon turunan hanya berisi 2 warna (latar `#3B4A5C` dan persegi terang `#F2F4F7`). `splash.png` dan `icon_foreground.png` hanya transparan plus satu persegi `#F2F4F7`. Tidak ada bentuk huruf atau gambar.

Konfigurasi sudah benar: `flutter_launcher_icons` dan `flutter_native_splash` di `pubspec.yaml` menunjuk `assets/branding/*`, dan generator sudah pernah dijalankan (W6 7.2/7.3), jadi `android/`, `ios/`, `macos/`, `web/` memang terisi, tetapi dengan kotak yang sama. Per platform:
- Android (splash, Android 12 splash, adaptive icon): kotak polos.
- iOS (LaunchImage, AppIcon): kotak polos.
- macOS (AppIcon), Windows (ico): kotak polos.
- Web (`web/splash/img/*`, favicon, `Icon-*.png`, `og.png`): kotak polos.
- Di dalam app Flutter tidak ada widget logo (`lib/` tidak memakai `Image`/asset branding), jadi satu-satunya logo adalah splash native dan ikon.

## Perbaikan
1. `2e370b9` fix(branding): monogram "S" (dua busur, goresan membulat, anti-alias) menggantikan kotak. Dibuat oleh `skeleton/tool/generate_branding.py` (stdlib saja, dapat diulang). Warna tetap `#3B4A5C` / `#F2F4F7`. Jalankan `python3 tool/generate_branding.py` dari `skeleton/`.
2. `014c6e6` chore: `dart run flutter_launcher_icons` dan `dart run flutter_native_splash:create`, lalu `web/og.png` disalin dari `assets/branding/og.png`. Perubahan generator yang tidak terkait (`project.pbxproj`, `Info.plist`, `web/index.html`) dikembalikan seperti pola W6. Konfigurasi tidak diubah.
3. `c2e2b5f` test(platform): `branding_assets_test.dart` kini mendekode 10 PNG (aset sumber dan turunan web/android/ios/macos) dan menolak gambar yang porsi pikselnya di luar 3-50% atau yang hanya punya <=4 warna (tanpa tepi anti-alias). Diuji: `icon.png` lama (kotak) membuat tes gagal.

`dart run tool/check.dart` exit 0 (338 tes lulus).

Terang/gelap: splash dan ikon memakai latar `#3B4A5C` dan glyph `#F2F4F7` di kedua mode (konfigurasi splash tidak punya varian gelap), kontrasnya jelas di keduanya. Tampilan dilihat dari `icon.png` saja.

## Tidak bisa dibuktikan tanpa perangkat
- Tampilan splash native di Android/iOS (termasuk masking lingkaran Android 12 dan adaptive icon) dan ikon di launcher/Dock. Hanya PNG di folder resource yang diperiksa.
- Splash web di browser (tidak menjalankan `flutter build web` atau screenshot).
- Sistem bisa meng-cache ikon/splash lama: uninstall app atau hard refresh saat mencoba.
- Ikon masih placeholder; ganti dengan artwork asli sebelum rilis.
