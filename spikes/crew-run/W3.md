- Commit pertama 5.2 sempat ikut menyapu file W2 yang sudah ter-stage (design/tokens.yaml, test/tool/tokens_yaml_test.dart). Saya `reset --soft` dan commit ulang hanya dengan path (4ab7de4). Commit W2/W3.1 lain tidak tersentuh.
