# C7 — Icon set (S23)
- Date: 2026-11-17
- Results: S23: pub.dev search `lucide` gave these candidates (checked via pub.dev API on 2026-11-17). `lucide_icons_flutter` 4.0.3 (2026-11-10, MIT, 214 likes, 160 pub points, all platforms incl. web and macos) ships six stroke weights (100 to 600) as separate fonts and Dart classes (`LucideIcons300` etc., import `package:lucide_icons_flutter/lucide_icons_300.dart`). `flutter_lucide` 1.72.0 (2026-11-12, MIT, 94 likes) and `lucide_flutter` 1.74.0 (2026-11-17, MIT, 4 likes) are newer but have no stroke-weight choice that I found in their metadata (README not inspected in depth). `lucide_icons` 0.257.0 (2023-06, ISC) is stale. Golden `spikes/icon_spike/test/goldens/icons.png` renders the 10 icons at 14/16/20 px: Lucide weight 300 on the left, Material Symbols Rounded weight 300 (`material_symbols_icons` 4.2960.0) on the right. All 10 Lucide icons exist under the expected names (search, plus, x, check, chevronDown, copy, trash, settings, bookmark, externalLink). Lucide 300 reads clearly at 14 px, with a bit more visual weight than Material at 300 (Material uses default opsz 48, so it looks thin at small sizes). Weight is picked by choosing the class, not a runtime parameter, so one weight means one font file in the bundle. Decision: plan kept, use `lucide_icons_flutter` with `LucideIcons300` (try 400 if the design needs more weight); fallback is Material Symbols Rounded via `material_symbols_icons`, which has a runtime `weight` parameter.
